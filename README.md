# Трекер задач ЕГЭ

Сайт, на котором видно, какие задачи ЕГЭ уже прошёл каждый класс.

- **Ученики и все остальные** просто открывают сайт: без входа видно прогресс по классам
  (сеткой или списком с темами) и сравнение классов по предмету.
- **Администраторы** (учителя) входят по адресу `/admin` и отмечают задачи: «пройдена»,
  «в процессе» или «не начата», с датой. Каждый учитель может редактировать **только свои
  предметы** (например, математик — только математику): отмечать задачи по всем классам
  и менять темы и количество задач.
- **Главный администратор** может всё: создаёт предметы и классы, добавляет учителей
  и выдаёт им права на предметы (вкладка «Администраторы» → «Права»).

## Что нужно

- [Node.js](https://nodejs.org) версии **22.13 или новее** (база данных SQLite встроена в Node,
  ничего отдельно ставить не нужно).

## Запуск

```bash
npm install
npm start
```

Сайт откроется на http://localhost:3000.

При **первом** запуске в консоли появится логин и пароль главного администратора:

```
==============================================
 Создан главный администратор
   логин:  admin
   пароль: Xy7kP2qA
==============================================
```

Сохраните его, войдите на `/admin` и смените пароль во вкладке «Мой аккаунт».
Если хотите задать логин и пароль сами, перед первым запуском укажите переменные
`ADMIN_USERNAME` и `ADMIN_PASSWORD`.

## С чего начать

1. **Предметы** → «Добавить предмет»: например, «Математика (профиль)», 19 задач.
   Темы задач можно вставить списком, по одной на строку.
2. **Классы** → «Добавить класс»: например, «11А», отметить нужные предметы.
3. **Администраторы** → добавить аккаунты учителей и отметить, какие предметы каждый ведёт.
4. **Отметки** → выбрать класс, нажать на номер задачи и выбрать статус.

## Тестовые данные

Чтобы посмотреть, как выглядит заполненный сайт, не вводя всё вручную:

```bash
npm run seed
```

Скрипт добавит 5 предметов с темами задач, 5 классов (10А–11В), отметки с сентября по сегодня
и учителей `ivanova` (математика), `petrova` (русский), `sidorov` (физика и информатика),
`kuznetsova` (обществознание) и `novikov` (без предметов). Пароль у всех учителей — `test1234`.

Если в базе уже есть предметы или классы, скрипт ничего не сделает. Команда
`npm run seed -- --reset` **удалит все предметы, классы и отметки** и заполнит базу заново.
Главный администратор и другие аккаунты останутся, но у учителей пропадут права на предметы
(предметов-то больше нет). Сервер можно не останавливать.

Чтобы не трогать настоящую базу, заполните отдельную и запустите сайт с ней:

```bash
DATA_DIR=data/demo npm run seed
DATA_DIR=data/demo npm start
```

> Только для проверки на своём компьютере. На настоящем школьном сервере не запускайте:
> у тестовых учителей простой общий пароль.

## Настройки (переменные окружения)

| Переменная        | По умолчанию | Что делает |
|-------------------|--------------|------------|
| `PORT`            | `3000`       | Порт сайта |
| `DATA_DIR`        | `./data`     | Папка с базой данных `ege.db` |
| `ADMIN_USERNAME`  | `admin`      | Логин первого администратора (только при первом запуске) |
| `ADMIN_PASSWORD`  | случайный    | Пароль первого администратора (только при первом запуске) |
| `TRUST_PROXY`     | —            | Поставьте `1`, если сайт стоит за nginx/другим прокси |
| `BACKUP_DIR`      | `./data/backups` | Куда сохранять ежедневные резервные копии |
| `BACKUP_KEEP`     | `30`         | Сколько последних копий хранить |

## Установка на школьный сервер (Linux)

```bash
# 1. Скопировать папку проекта на сервер, например в /opt/ege_track
cd /opt/ege_track
npm install --omit=dev

# 2. Запускать как службу, чтобы сайт поднимался после перезагрузки
sudo tee /etc/systemd/system/ege-track.service > /dev/null <<'EOF'
[Unit]
Description=EGE tracker
After=network.target

[Service]
WorkingDirectory=/opt/ege_track
ExecStart=/usr/bin/npm start
Environment=PORT=3000
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
EOF

sudo chown -R www-data /opt/ege_track
sudo systemctl enable --now ege-track
journalctl -u ege-track | grep -A3 "главный"   # пароль первого админа
```

На Windows-сервере можно использовать [pm2](https://pm2.keymetrics.io/) (`npm i -g pm2`,
`pm2 start npm --name ege-track -- start`) или просто `npm start`.

Если сайт будет доступен из интернета — лучше поставить перед ним nginx с HTTPS
и указать `TRUST_PROXY=1`.

## Резервные копии

Сервер **сам раз в день** сохраняет копию базы в `data/backups/ege-ГГГГ-ММ-ДД.db`
и хранит последние 30 копий, более старые удаляет. Копия делается без остановки сайта
и весит около 100–200 КБ. Сделать копию прямо сейчас:

```bash
npm run backup
```

### Копии в Google Диске

Копии на том же компьютере не спасут, если сломается сам диск, поэтому удобно отправлять
их в Google Диск. Сайт для этого ничего не знает про Google — он просто кладёт файлы
в папку, а синхронизацией занимается отдельная программа.

**Windows.** Установите [Google Диск для компьютера](https://www.google.com/drive/download/),
войдите в аккаунт, создайте в Google Диске папку, например «ЕГЭ бэкапы», и укажите её
в `BACKUP_DIR` (буква диска может быть другой):

```powershell
$env:BACKUP_DIR = 'G:\Мой диск\ЕГЭ бэкапы'; npm start
```

**Linux** (официального клиента Google Диска нет) — через [rclone](https://rclone.org/drive/):

```bash
sudo apt install rclone
rclone config                     # создать подключение «gdrive» к своему Google Диску
# раз в час отправлять копии в папку «ЕГЭ бэкапы»; sync удаляет в облаке то,
# что сайт удалил локально, поэтому там тоже будут последние 30 копий
(crontab -l; echo '0 * * * * rclone sync /opt/ege_track/data/backups "gdrive:ЕГЭ бэкапы"') | crontab -
```

### Восстановление из копии

1. Остановите сервер.
2. В папке `data/` удалите `ege.db`, `ege.db-wal` и `ege.db-shm`.
3. Скопируйте нужную копию, например `ege-2026-10-25.db`, в `data/ege.db`.
4. Запустите сервер.
